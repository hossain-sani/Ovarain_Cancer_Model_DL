Experiment 1 requirements
=========================
No new packages are needed on top of the root requirements.txt.

This experiment reuses:
  - torch / torchvision  (EfficientNet_B0_Weights needs torchvision >= 0.13)
  - numpy, pandas, scikit-learn
  - xgboost, shap
  - opencv-python-headless (bilateral filter preprocessing)
  - Pillow

The root `pip install -r requirements.txt` already covers everything.
First run downloads the ImageNet-pretrained EfficientNet-B0 weights
(~20 MB) automatically.
